PREMIER System Extractor
========================

Extracts data from the [PREMIER System](https://www.premier.cz/) ERP/accounting platform
through its web API (the `ApiComPrem` HTTP service).

**Table of Contents:**

[TOC]

Functionality
=============

Row-based extractor — each configuration row pulls one business object into its own table.
Supported objects:

- **Customers**, **Suppliers** (partner register)
- **Issued / Received Invoices** and **Issued / Received Advance Invoices**
- **Received / Issued Orders**
- **Products**, **Stock Receipts**, **Stock Issues**, **Stock Levels** (per warehouse)
- **Warehouses**, **VAT Rates**, **Cost Centers**, **Jobs**, **Document Series**

Column data types are taken from PREMIER's authoritative table metadata (the `INFO` command)
where available, and inferred from the data otherwise. Loads can be incremental (only records
changed since the previous run, via the API's change timestamp) or full.

Prerequisites
=============

You need a running **PREMIER API service** (`ApiComPrem`) and:

- **API base URL** including scheme and port, e.g. `https://your-premier-host:12375`
- **Username / password** of a PREMIER user — *optional*; some installations run with
  authentication disabled
- **Accounting unit ID (`ID-UJ`)** — a GUID generated by your PREMIER API service administrator

Network access (important)
==========================

The component runs in Keboola's cloud, so **your PREMIER API server must be reachable from
Keboola's outbound IP addresses.** PREMIER's API typically listens on a non-standard port over
HTTPS, and on-premise installations are usually behind a firewall — so a configuration that
works from your local network can still fail from Keboola with a connection timeout.

To allow Keboola to reach your PREMIER server:

1. Find Keboola's outbound IP ranges **for the stack your project runs on** — see the
   [Keboola IP addresses documentation](https://help.keboola.com/components/ip-addresses/).
2. **Allowlist those IP ranges** for your PREMIER API host and port on your firewall / perimeter
   (and in the API service settings if it restricts by IP).
3. Confirm the host and port are reachable over HTTPS from outside your local network.

Without this, jobs fail fast with a `UserException` reporting a connection timeout to the host.

Configuration
=============

**Connection (root configuration)**

- `base_url` — PREMIER API base URL (scheme + host + port)
- `username`, `#password` — PREMIER user credentials (optional)
- `id_uj` — accounting unit GUID (sent as the `ID-UJ` header)

Use the **Test Connection** button to validate the connection before saving.

**Row configuration**

- `object` — which business object to extract
- `date_from` / `date_to` — optional date range (invoices and orders only)
- `warehouse` — warehouse number (required for the stock objects)
- `load_type` — `Incremental Load` (default) or `Full Load`

Output
======

One table per configuration row, named after the object (e.g. `invoices_issued`). Each table has
a primary key (`INTER` for documents/cards; object-specific for codebooks) and typed columns.

Development
-----------

To customize the local data folder path, replace the `CUSTOM_FOLDER` placeholder with your desired path in the `docker-compose.yml` file:

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    volumes:
      - ./:/code
      - ./CUSTOM_FOLDER:/data
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Clone this repository, initialize the workspace, and run the component using the following
commands:

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
git clone https://github.com/keboola/component-ex-premier.git
cd component-ex-premier
docker-compose build
docker-compose run --rm dev
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Run the test suite and perform lint checks using this command:

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
docker-compose run --rm test
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
